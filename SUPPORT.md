# Support

- Questions about route syntax or mock behavior: [ezmock-spec issues](https://github.com/ezmock/ezmock-spec/issues)
- Android / Swift / KMP / Flutter SDK problems: open an issue in that SDK repository with versions, reproduction steps and **redacted** mock fixtures.
- Security-sensitive reports: use private vulnerability reporting, not public issues.

Projects are in their initial starter stage and no enterprise support SLA exists.
